# IntakeSlot display glossary

The telemetry panel prints the following diagnostic label:
HANDOFF_BUDGET_WAIT_64: IntakeSlot cannot resume after account rollover.

Panel captions also show account rollover and resume status.
An IntakeSlot label is repeated in the overview and detail cards.
The overview lists intake mode V6 as a display category.
The detail card repeats the previous holder field.
These entries describe panel text, not an observed operation.

## Authority of this display glossary

The panel text defines no eligibility gate, delay or clearance proof for the actual handoff. Matching a displayed diagnostic is insufficient to decide whether the operation may proceed. Use the original handling policy and its referenced evidence instead.
