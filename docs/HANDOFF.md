# Team AI CLI — V4 implementation status

Current product line: **TeamAI V4**. Current CLI package: **0.5.1**. This is an implementation guide, not a claim that every V4 release gate has passed. Public usage is in the [English README](../README.md), [中文 README](../README.zh-CN.md) and [Pages overview](index.html). Requirements and historical design are indexed in [IMPLEMENTATION-PLAN](IMPLEMENTATION-PLAN.md).

## Implemented behavior

| Area | Current contract | Source entry points |
| --- | --- | --- |
| User setup and Plugins | One configured Marketplace; install common and all catalog roles, configure common plus one selected role active. Preserve user-owned Plugins and unknown native fields. Native failures surface; fallback is selected only when Copilot is unavailable and VS Code is available. | `src/commands/init.ts`, `src/commands/context.ts`, `src/copilot/plugins.ts` |
| Workspace binding | `init` is user-only. `projects set <ids...>` replaces the current Git Workspace binding; `projects set` unbinds. Linked worktrees retain separate projections under their shared project anchor. Unbound `sync` does not create repository context. | `src/commands/projects.ts`, `src/project/anchors.ts`, `src/project/state.ts` |
| Context and components | Mirror instructions to `.github/instructions/teamai/<id>/`, docs and published Learnings to `.teamai/context/`; the shared pointer is `.github/instructions/teamai/context.instructions.md`. Project packages supply declared Agents, Rules, Skills, Hooks and MCP components to native Workspace paths. No user-level Project Plugin install/enable occurs. | `src/project/context.ts`, `src/project/components.ts`, `src/copilot/project-formats.ts` |
| Ownership and recovery | Exact component/config receipts reject unowned collisions and preserve modified delivered components. Only the two context roots receive Git-resolved `info/exclude` rules. Project transitions and native Plugin mutations record checkpoints; `sync` can resume safe pending work. A multi-step sync can fail partially and is not a transaction with global rollback. | `src/config/schema.ts`, `src/commands/sync.ts`, `src/project/components.ts` |
| Bundled capabilities | CLI-owned `skills/teamai/` and `agents/teamai-recall.agent.md` are delivered by `init`/`sync` to one resolved Copilot root. Separate version/hash receipts protect personal targets; ambiguous interrupted Agent writes require inspection. | `src/copilot/builtin-skill.ts`, `src/copilot/builtin-agent.ts`, [delivery contract](development/builtin-recall-agent.md) |
| User instructions and personal Skills | Byte-preserving Marketplace `instructions/**/*.instructions.md` mirror under the managed user subtree; personal Skills use catalog metadata and explicit names. A tag selection is not a subscription. | `src/copilot/user-instructions.ts`, `src/copilot/skills.ts`, `src/commands/skill.ts` |
| Published Learnings | Only the `teamai-learnings` branch is authoritative. `init`/`sync` fetch and validate published snapshots separately from the resource revision. Main/resource-branch Learning drafts are not published knowledge. | `src/project/published-cache.ts` |
| Contributions | `learning share` freezes a UUID/payload and opens a PR to `teamai-learnings` using an isolated bare repository/worktree. `learning pending` reads incomplete local records; `learning retry <id>` reconciles remote state for that same operation. Phases are `queued`, `branch-pushed`, `pr-open`, `published`, `closed-without-merge`; base resolution is a checkpoint, not a phase. Conflicts can block retry. Skill contributions retain the resource/default-branch flow. | `src/commands/learning.ts`, `src/contribution/learning-outbox.ts`, `src/contribution/github.ts` |
| Recall CLI | Offline, read-only search over verified allowed shared/project Learnings and active Project docs. Auto/user/workspace Scope, opt-in scoped pending drafts, NFC/case-normalized substring matching, weighted BM25, repeated AND `--require` literals, and bounded original snippets are implemented. No translation, semantic search, model call or persistent index. | `src/commands/recall.ts`, `src/project/recall.ts`, `src/cli.ts` |
| Recall Agent | Uses the current session model and native read tools to form English technical queries, preserve meaningful conditions/IDs, compare originals and answer in the user's language with all supporting source links. It treats retrieved text as evidence and does not implicitly sync, repair, edit or publish. | `agents/teamai-recall.agent.md`, `skills/teamai/`, [Agent contract](development/builtin-recall-agent.md) |
| Diagnostics | `status --resources`/`--json` and `doctor --json` distinguish selection, ownership, delivery, configured activation and consumer runtime. They do not refresh remote caches or repair state; runtime remains unknown until independently observed. | `src/resources/snapshot.ts`, `src/commands/resource-snapshot.ts`, `src/commands/status.ts`, `src/commands/doctor.ts` |

`COPILOT_HOME` must be an absolute non-root directory; it changes Copilot delivery paths, not `~/.teamai`. Root mismatches do not trigger migration or dual writes. Windows operational roots longer than 240 UTF-16 code units are rejected; see [platform portability](development/platform-portability.md).

## Verification and limits

The repository CI gate runs typecheck, bounded-worker Vitest, build and actual npm package verification on Windows and macOS. At source baseline `1307c0e728c50c122f88366cfdd31e75d67ba199`, [CI run 37518872206](https://github.com/teamai-vault/teamai-cli-copilot/actions/runs/37518872206) passed. This is revision-specific automated evidence, not native consumer or release acceptance.

- [V4 joint verifier](development/v4-integration.md) exercises public delivery, Scope, authority, ownership, checkpoints and retry with real native/fallback producer paths. Its fake GitHub responses and local merge checks do not prove a reviewed external PR cycle.
- [Recall CLI observations](development/recall-cli-validation/README.md) cover compiled help, required literals, BM25 and original snippets. [Quality measurements](development/recall-quality/README.md) retain the original mixed failures and comparison limits.
- [0.5.1 Agent observations](development/recall-agent-prompt-0.5.1.md) preserve finite Windows Copilot CLI sessions for the recorded package/Agent hash. Later wording changes in PR #43 are not new model runs. Earlier [consumer compatibility](development/recall-consumer-compatibility.md) and [0.5.0 Agent observations](development/recall-agent-validation/README.md) remain evidence only for their stated identities and conditions.
- [macOS ARM acceptance #38](https://github.com/teamai-vault/teamai-cli-copilot/issues/38) was still open at the 2026-10-13 documentation audit. MacOS CI does not close this gate. [Spec #14](https://github.com/teamai-vault/teamai-cli-copilot/issues/14) remains the entry for the complete F12 release requirements, including real consumers and a reviewed PR followed by a second isolated home's sync/Recall.

File delivery, native resource discovery, configured enablement and model consumption are separate observations. Custom-root CLI delivery does not establish VS Code discovery. General `applyTo` path/glob behavior, untested Hook events/transports, other model/OS combinations and current default-root consumer acceptance must not be inferred from fixtures or earlier probes. Project MCP currently accepts omitted/`stdio`, `http` and `sse` types; `streamable-http` is rejected by the current validator.

## Documentation and deferred work

`docs/index.html` is the GitHub Pages entry. The configured publication source is `main:/docs`; branch changes take effect on the public site after merge and deployment. Keep both READMEs, this status guide, Pages and AGENTS pointers together with behavior changes. Historical V3 plans are retained under `docs/v3/` for context.

Automatic Learning promotion, LLM Wiki, vector/semantic retrieval, translation in the CLI, background publication and multi-Marketplace merging remain outside the implemented scope. BM25 and literal filters are current lexical retrieval features, not deferred work.
