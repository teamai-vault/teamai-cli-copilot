团队的 Copilot 配置，
一条命令同步到位。

Marketplace 定义 Plugins、Instructions、Skills 和团队经验。teamai 把它们装到你的机器和 Repo，并保持收敛。

3 分钟上手 看架构 
$ teamai init --marketplace <owner/repo> --role api
$ cd payment-service
$ teamai projects set payments
$ teamai sync
$ teamai recall 支付 重试
设置一次 init，绑定一次 projects set，之后只需 sync。

一张图看懂。

Marketplace 是唯一内容源。CLI 只做控制面：通过 Copilot 原生命令管理 Plugins，把其余内容按归属写到两个范围。

读取与收敛贡献回流，Marketplace 维护者审核

Marketplace 里的每个目录，去了哪里。

CLI 和 Marketplace 是两个独立仓库，靠目录约定对接。维护者只改 Marketplace，CLI 按下表消费。参考实现见 teamai-marketplace。

Plugin 的类型只看 plugin.json 里的 extensions.com.company.teamai.kind，不看名字。project Plugin 只在 projects.yaml 用 plugin: 引用时才被消费。

先认识几个词。

分两组记：跟人走的装到你的机器，跟业务走的装到 Repo。

跟人走 · 你的机器

Marketplace部门仓库
一个 Git 仓库，部门共同维护。CLI 不内置任何 Marketplace，每个用户用 init 指定一个。
PluginAgent Plugin
Copilot 原生扩展包。按 extensions.com.company.teamai.kind 分为 common、role、project。
Role你的岗位
api、ios、aos、qa、design 之一。决定启用哪个 role Plugin。
Skill按需加载的能力
一个 SKILL.md 目录。随 Plugin 提供，或作为 standalone 单独安装。
Instructions常驻规则
*.instructions.md。部门级的逐字节镜像到 ~/.copilot/instructions/teamai/。
Recall Agent内置
随 CLI 分发的 teamai-recall Agent。只读检索团队知识，带出处回答，不改代码。

跟业务走 · 当前 Repo

Logical Project业务项目
业务意义上的项目，如 payments，在 manifest/projects.yaml 声明。可以横跨多个 Repo。
Physical Project本地 Repo
你本地的一个 Git 工作区。用 projects set 绑定一个或多个 Logical Project。
Context业务上下文
Logical Project 的 Instructions 和 Docs。绑定后写入 Repo，Copilot 在这里就懂这块业务。
Learning团队经验
一篇排障或踩坑记录。经 PR 合入 teamai-learnings 分支后成为已发布内容。
Project Plugin可选
只是组件来源。CLI 把 manifest 选中的 Agents、Rules、Skills、Hooks、MCP 投射到 Repo 的原生位置，不会安装或启用这个包。

一次 sync 做了什么

先整体预检，任何一步不通过就不写入。之后每一步都只动 teamai 拥有的东西。

  1. 刷新 Marketplace 与已发布 Learnings 快照main + teamai-learnings
  2. 预检全部收敛计划dry-run
  3. 内置 Recall Agentagents/teamai-recall.agent.md
  4. 内置 teamai Skillskills/teamai/
  5. 用户级 Instructions 镜像instructions/teamai/
  6. Plugins 安装与启用copilot plugins …
  7. VS Code Marketplace 注册chat.plugins.marketplaces
  8. 当前 Repo 的 Context、组件与 Learnings仅当已绑定
  9. 已安装的个人 Skills~/.copilot/skills/

从零到可用。

需要 Node.js 20+ 和 Git。Plugins 收敛需要 GitHub Copilot CLI（copilot），没有时回退到 VS Code（code）。

安装

目前从源码安装，npm link 后即可全局使用 teamai。

$ git clone https://github.com/teamai-vault/teamai-cli-copilot.git
$ cd teamai-cli-copilot
$ npm install && npm run build && npm link
$ teamai --version

初始化自己

所有 role Plugin 都会安装，只启用 common 和你的 Role。非交互环境必须同时给出两个参数。

$ teamai init --marketplace <owner/repo> --role api

DONE plugin-install: common@teamai
DONE plugin-install: api@teamai
DONE plugin-install: ios@teamai
DONE plugin-disable: ios@teamai
...
DONE create: ~/.copilot/instructions/teamai/global.instructions.md

输出为节选。不确定时先加 --dry-run。

绑定 Repo

进入业务 Repo，告诉 teamai 它属于哪个 Logical Project。可以多个，空格或逗号分隔。

$ cd payment-service
$ teamai projects list
$ teamai projects set payments
DONE write: .github/instructions/teamai/payments/context.instructions.md
DONE write: .teamai/context/payments/docs/architecture.md
DONE write: .teamai/context/shared/learnings/<uuid>.md
DONE write: .git/info/exclude

路径已缩短为相对 Repo 根目录。两个保留目录自动加入 Git exclude。

保持最新

团队更新了 Plugins、文档、Skills 或 Learnings 之后，在 Repo 里跑一次。已收敛时不写任何东西。

$ teamai sync
Copilot plugin state is already converged.
Managed user instructions are already converged (2).

它会写到哪里。

只管理高亮的路径，并为每一处写入记录所有权回执。路径已被别人占用时直接拒绝，不会覆盖。

doctor 只读

检查缺失、过期和冲突，不刷新缓存也不修复。修复交给 sync。

status 看全貌

Marketplace revision、Role、Plugin 开关、Repo 绑定。--resources 逐项列出资源的交付与归属，--json 给工具用。

--dry-run 先预览

所有写命令都支持，只打印 WOULD ...，不改任何状态。

全部命令。

精确语法以 teamai --help 和 teamai <command> --help 为准。

设置与 Repo

init [--marketplace <source>] [--role <role>]
配置你自己，只影响你的机器。
role list · role set <role>
查看或切换 Role。
projects [list] · projects set <ids...>
查看 Logical Project，绑定当前 Repo。
sync
刷新并收敛你的机器和当前 Repo。

召回

recall <query> [--scope auto|user|workspace]
本地检索已发布 Learnings 与 Project Docs。
[--project <id>] [--limit <n>]
收窄 Project，限制条数。
[--include-pending] [--json]
带上本地草稿，输出 JSON。

Skills

skill list [--tag] [--owner] [--source]
浏览团队 Skill 目录。
skill show <name>
来源、Owner、Tag、本地状态。
skill install <name...> · --tag <tag> [--yes]
按名字或按 Tag 安装。
skill remove <name...> · tags list
移除 teamai 安装的 Skill，查看全部 Tag。

贡献

learning share <file> [--project <id> | --shared] [--tags]
提交到 teamai-learnings。只有一个绑定时默认用它，没有绑定时用 shared。
learning pending [--json] · learning retry <id>
查看未完成的贡献，从检查点续传。
skill contribute <path> --owner <o> --target standalone|plugin
贡献为 standalone，或配合 --plugin 放进已有 Plugin。

诊断

status [--resources] [--json]
状态总览，或逐项资源清单。
doctor [--json]
只读诊断。

Marketplace 维护者

node scripts/init-learnings-branch.mjs --marketplace <url> [--apply]
初始化 teamai-learnings 分支，默认只预览。
npm run rename:marketplace -- --from <a> --to <b> --dry-run
重命名 Marketplace 逻辑 ID。
全局选项：--dry-run 预览所有写入和 Copilot 变更，--version 查看版本，--help 查看帮助。
